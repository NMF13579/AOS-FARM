# AOS Root Install Guide

This file is inside the `/aos/root/` template support area.

## Manual Transfer Steps
For manual transfer, the first reviewed step is: Copy `/aos/` into the target repository root.
Do not manually overwrite existing root files without review. For the full transfer flow, use the install/transfer authority: [../docs/INSTALL-AND-TRANSFER.md](../docs/INSTALL-AND-TRANSFER.md).

- If target root already has `/aos/`, `AGENTS.md`, `llms.txt`, or conflicting root files, stop for human review.
- PASS/Evidence do not imply approval.
